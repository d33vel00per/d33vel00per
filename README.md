## Чем занимаюсь

Делаю **NitroFrame** — приложение, которое собирает системные твики Windows, мониторинг оборудования и игровые инструменты в одном интерфейсе. Без «магической кнопки FPS»: видно, что именно включено, изменения применяются осознанно и откатываются обратно.

<table>
<tr>
<td width="50%" valign="top">

### Основное в проекте

- профили системных твиков вместо ручного реестра;
- резервное состояние перед изменениями и восстановление;
- мониторинг CPU, GPU, RAM и VRAM в реальном времени;
- игровой режим и связанные оптимизации;
- аккаунт, лицензия и проверка версий на сервере;
- отдельный updater для обновлений.

</td>
<td width="50%" valign="top">

### Стек и инструменты

- **C# / .NET 8** — приложение и updater;
- **WPF** — интерфейс;
- **Windows API, реестр, WMI** — системный слой;
- **серверная часть** — лицензии, версии, обновления;
- **Inno Setup** — установщик и релизные сборки.

</td>
</tr>
</table>
